# ORRIN · Links

Link page for ORRIN, a voice assistant that runs on your own PC. Live at **https://xaeus99.github.io/**

## Add a link
Open `index.html`, find the `LINKS` list near the top, and add a line:

```js
{ label: "ORRIN on TikTok", url: "https://www.tiktok.com/@yourname", icon: "tiktok" },
```

Icons: `download`, `itch`, `play`, `web`, `tiktok`, `instagram`, `youtube`, `x`, `discord`, `github`. Add `primary: true` for a big orange button. Commit, and GitHub Pages updates in about a minute.

Plain static HTML, no build step. MIT licensed.
